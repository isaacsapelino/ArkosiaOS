# ArkosiaOS 
A hobby operating system written in x86 Assembly

## Features
- BIOS Bootloader
- FAT12 support
- LBA to CHS conversion
- INT 13h disk reading
- Kernel Loading (planned)
- Protected mode (planned)

## Project Structure
```
/boot 

```
